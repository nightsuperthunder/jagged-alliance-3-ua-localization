<GAME> — українська локалізація (фанатська)
==============================================

ВСТАНОВЛЕННЯ
1. Steam → <GAME> → ПКМ → Керування → Переглянути локальні файли.
2. Розпакуйте ВЕСЬ вміст архіву в цю папку (поруч з <GAME>.exe).
   Має вийти: <GAME>.exe, winhttp.dll, doorstop_config.ini, папка BepInEx.
3. Запустіть гру. Якщо мова Windows українська — гра одразу буде українською.
   Інакше: Налаштування → Мова → «Українська».

Файли гри не змінюються, тож оновлення гри переклад не ламають.

ВИДАЛЕННЯ
Видаліть winhttp.dll, doorstop_config.ini і папку BepInEx з папки гри.

ДЛЯ ПЕРЕКЛАДАЧІВ
- Переклад: BepInEx/plugins/<MOD>/translations/uk.json
  (таблиця → ID рядка → текст; відсутні рядки показуються англійською).
- Шрифти: покладіть .ttf/.otf з кирилицею в BepInEx/plugins/<MOD>/fonts/
    default.ttf                    — для всього тексту;
    <назва шрифту гри>.ttf         — для конкретного шрифту.
  Без шрифтів використовується системний Georgia (змінюється в BepInEx/config/<GUID>.cfg).
- Журнал: BepInEx/LogOutput.log

Використовується BepInEx 5 (https://github.com/BepInEx/BepInEx, LGPL-2.1).
