# Українська локалізація Jagged Alliance 3

Фанатський переклад **усього тексту гри** українською: інтерфейс, діалоги, сценки найманців, квести, предмети,
підказки, енциклопедія, субтитри (≈ 30 тис. рядків, ≈ 300 тис. слів). Озвучення лишається англійським.

Це звичайний мод для вбудованого **Mod Manager**: файли гри не змінюються, оновлення гри мод не ламають,
вимкнути чи видалити його можна будь-коли. Шрифти гри мають кирилицю — нічого додатково ставити не треба.

> **Версія 1.0.** Перекладено все. Помилки, обрізаний текст чи англійські
> рядки — повідомляйте (див. [Зворотний зв’язок](#зворотний-звязок)).

## Встановлення

Завантажте архів `JA3_Ukrainian_Localization-v….zip` зі сторінки [Releases](../../releases/latest).

### Автоматично (Windows)
1. Розпакуйте **весь** архів у будь-яку теку.
2. Запустіть `install.bat`.
   Якщо Windows покаже «Windows захистила ваш ПК» — «Докладніше» → «Виконати все одно».
   Скрипт лише копіює теку `JA3UkrLoc` у `%AppData%\Jagged Alliance 3\Mods` (його можна відкрити Блокнотом і перевірити).
3. Запустіть гру → **Mod Manager** → увімкніть **«Українська локалізація»**.
4. Мова гри — **English**: Options → Gameplay → Language → English
   (переклад підміняє англійський текст; з іншою мовою гри мод не діє).
5. Якщо текст лишився англійським — перезапустіть гру.

### Вручну (без скриптів)
1. Win+R → `%AppData%\Jagged Alliance 3` → Enter (тека налаштувань гри: там є `Saves`, `logs`).
2. Створіть у ній теку `Mods`, якщо її немає.
3. Скопіюйте з архіву теку `JA3UkrLoc` у `Mods`. Має вийти:
   ```
   %AppData%\Jagged Alliance 3\Mods\JA3UkrLoc\metadata.lua
   %AppData%\Jagged Alliance 3\Mods\JA3UkrLoc\items.lua
   %AppData%\Jagged Alliance 3\Mods\JA3UkrLoc\English.csv
   %AppData%\Jagged Alliance 3\Mods\JA3UkrLoc\Code\UkrLoc.lua
   ```
   Без зайвої вкладеної теки (`JA3UkrLoc\JA3UkrLoc\…`) і без перейменування.
4. Далі — кроки 3–5 автоматичного встановлення.

### Steam Deck / Linux (Proton)
Та сама тека — всередині префікса Proton (1084160 — Steam ID гри):
```
~/.local/share/Steam/steamapps/compatdata/1084160/pfx/drive_c/users/steamuser/AppData/Roaming/Jagged Alliance 3/Mods/
```
Якщо гра в іншій бібліотеці Steam (напр. на SD-картці) — замість `~/.local/share/Steam` шлях до цієї бібліотеки.
Скопіюйте туди теку `JA3UkrLoc`, далі — як вище.

### Оновлення та видалення
- **Оновлення:** встановіть нову версію так само — стара тека `JA3UkrLoc` замінюється повністю. Збереження не зачіпаються.
- **Видалення:** вимкніть мод у Mod Manager, або `uninstall.bat`, або видаліть теку
  `%AppData%\Jagged Alliance 3\Mods\JA3UkrLoc`.

### Якщо щось не так
| Проблема | Що робити |
|---|---|
| Мода немає в Mod Manager | Перевірте шлях (часто — зайва вкладена тека) |
| Мод увімкнено, а текст англійський | Мова гри — English; перезапустіть гру |
| `install.bat` пише, що немає теки `JA3UkrLoc` | Розпакуйте архів повністю, не запускайте скрипт із вікна архіву |
| Текст не влазить у кнопку чи вікно | Надішліть знімок екрана — скоротимо |

## Як зроблено
Переклад виконано локальними мовними моделями з глосарієм (імена найманців з їхньою статтю, назви місць і
термінів) і кількома автоматичними перевірками: теги й підстановки, рід мовця, «ти/ви», переклади, що
«з’їхали» на сусідній рядок, смислові помилки; складні рядки вичитано вручну. Вирішено:
- до гравця-командира — «ви»; імена й прізвиська транслітеровано;
- AP → ОД, HP → ОЗ, Overwatch → Пильність, Sat View → Супутникова мапа;
- французькі вставки лишаються латиницею, російські — латинською транслітерацією;
- лайка — українська, без мату.

## Збирання з вихідників
Потрібні Python 3.14+ і встановлена гра. Оригінальних текстів гри в репозиторії немає — лише переклад
(`work/translations.json`) і хеш кожного вихідного рядка.

```
python scripts/export_strings.py     # тексти гри -> work/strings.json (локально)
python scripts/build_mod.py          # work/translations.json -> mod/JA3_Ukrainian_Localization.zip
python scripts/release.py 1.0.0      # версія + збірка + архів з номером версії
```

Деталі процесу — в [CLAUDE.md](CLAUDE.md).
