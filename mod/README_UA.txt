Українська локалізація Jagged Alliance 3 (фанатський переклад тексту; озвучення лишається англійським)

ВСТАНОВЛЕННЯ
1. Розпакуйте теку «JA3 Ukrainian Localization» в
   %AppData%\Jagged Alliance 3\Mods\
   (натисніть Win+R, вставте %AppData%\Jagged Alliance 3 і створіть теку Mods, якщо її немає).
2. Запустіть гру → Mod Manager → увімкніть «Українська локалізація».
3. Мова гри має бути English: Options → Gameplay → Language → English.
   (Переклад підміняє англійський текст; з іншою мовою гри мод не діє.)
4. Якщо текст лишився англійським — перезапустіть гру.

ВИДАЛЕННЯ
Вимкніть мод у Mod Manager або видаліть теку мода.

Знайшли помилку в перекладі? Напишіть, будь ласка: який рядок, що не так, і (якщо можна) знімок екрана.
